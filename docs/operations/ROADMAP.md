# Roadmap / gates (proposal, not completed work)

## H0: functional foundation and one user journey
G0 select country/segment/trigger/source. G1 typed API with synthetic tests. G2 evidence semantics with no false verification. G3 web UX E2E. G4 privacy/security tests. G5 controlled deployment and submission. G6 partner/user research and pivot decision.

Critical path: contract -> API -> frontend -> tests -> model access and verification source -> measured UX -> deployment. The existing offline baseline completes part of G1 but does not prove Meta model integration or verified source.

## H1: contextual checks
Consented local timeline, evidence receipt verifier, source registry, Meta model provider behind policy port, calibrated evaluation, click-triggered browser extension (if permissions supported).

## H2: platform pilots
Partner API key and tenant isolation, quotas/rate limits, independent source integrations, redacted metrics, B2B SLAs, optional consented secure storage, incident flows by country.

## H3: research/scale
Guardians on permitted mobile surfaces, federated threat intelligence only after evidence+legal basis, finance/Web3 adapters, cross-rail trust concept, internationalization, standard proposals.

## Stop criteria
Wrong answers causing material harm, unverifiable evidence presented as fact, personal data leaks, serious false-alarm burden, no viable data sources, uncertain authorization/terms or expenses beyond planned ceilings. Pause or remove risky feature; never silently downgrade protections.

Progress tracking lives in Issues and build log, not fictional done checkboxes.
