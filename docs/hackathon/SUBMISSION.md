- [ ] Confirm acceptance, category and official submission deadline/time zone.
- [ ] Verify final deliverables, repository/public access, video duration, disclosure and model usage rules.
- [ ] Show working E2E synthetic flow; state clearly offline limitations until Meta adapter is real.

- [ ] Screenshot/video capture no PII, credentials, private chats or unlicensed content.
- [ ] Correct deployed URLs and tested smoke steps.
- [ ] Distinguish built MVP from future vision and simulations.
- [ ] Record final commit SHA and CI run.
