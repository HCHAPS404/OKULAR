# Contributing

Start with \`AGENTS.md\` and the [branch guide](docs/engineering/BRANCHES.md). Open an Issue with acceptance criteria and data/privacy impact, create a short-lived branch, include tests in your PR, and avoid publishing any real victim data. All source code and docs must distinguish implemented functions from vision and simulated examples.

No new libraries, providers, databases or active monitoring without an ADR or scoped issue explaining necessity, security, cost and rollback.
