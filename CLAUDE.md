# Instructions for Claude / coding assistants

Read [AGENTS.md](AGENTS.md) before touching code. AGENTS.md is the single source of coding and safety rules. Read the complete [V4 master specification](docs/master/OKULAR-mega-prompt-maestro-v4-integral.md) for product scope; do not confuse vision with implemented features.

Work on the permanently assigned `area/<domain>` branch for a scoped Issue; optional temporary `task/<domain>/<issue>` branches isolate concurrent WIP. Use PR with merge commit into main, keep and synchronize the area branch. Document tests executed and known limitations. No invented model results, verifications, integrations or deployments.
